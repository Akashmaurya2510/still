# Still

Clean, calm to-do app. Liquid-glass chrome, OLED / light themes, local-only data.

## Features

- Add tasks (Enter, or press **N**)
- Star, Today, Tomorrow from the composer
- Lists: Everything, Starred, Inbox, Personal, Work
- Large All / Active / Done tabs
- Search
- Notes on a task
- Swipe right to complete, left to delete
- Progress, theme toggle
- Saved in your browser (localStorage)

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:8080

## Shortcuts

| Key | Action |
|-----|--------|
| N | Focus new task |
| Enter | Add / save |
| Esc | Cancel edit |
